High error rate on admin interface

Incident report for DatoCMS

Dates & times in UTC.

Resolved

A code change in the CMS conflicted with some plugins which made the user-interface unusable.

This didn't affect the APIs and only records that used certain plugins.

As soon as we got notified we issued a fix in the CMS. Unfortunately opening to third-party plugins opens to the possibility of complex scenarios that we haven't thought about. We have learnt something new from this incident and we'll try to prevent these issues from happening again in the future.
